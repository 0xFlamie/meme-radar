# Meme 雷达开源版 v0.1.12

本次重点修复 API 连接检测与错误提示。

## 本次更新

- **连接检测不再长时间排队**：请求通道被扫描占用时，立即说明等待原因，不再等到浏览器超时后误报网络失败。
- **失败原因更准确**：区分限频、额度不足、Key 无效、网络异常与上游服务异常；有可靠重试时间时直接显示。
- **提示不再被刷新覆盖**：保留本次测试结果，切换界面语言也能正确显示。
- **配置保存更稳妥**：取消或超时后不再后台补存 Key；更换失败保留原配置，错误提示不回显密钥或上游原始内容。

保留免费 API 的请求队列、退避与预算保护，不绕过 AVE 限速。此版本修复软件侧检测问题，不保证消除第三方限频、无效 Key 或用户网络故障。

## 下载与升级

下载下方对应系统的 ZIP，完整解压后启动。顶部“下载最新版”直达本仓库最新下载页，不会自动覆盖安装。

升级前关闭旧版并保留备份，需要迁移 Key、预算账本与设置时，请按 [README 的迁移步骤](https://github.com/nhovongoc0-max/meme-radar#下载最新版) 操作。不要公开本机 `state/`、日志或 API Key。

本版已通过自动化回归与 macOS 本地验证；Windows 便携包已做结构与文件校验，尚未完成本版 Windows 真机验收。
